개인정보처리방침

시행일: 2026년 11월 15일

본 방침은 "고라니_toon" 채널 운영자(이하 "운영자")가 내부 자동화 도구 Gorani Toon Autopilot(이하 "앱")을 사용하면서 처리하는 정보에 대해 설명합니다.

1. 앱의 용도

앱은 운영자 본인이 소유한 Instagram, Threads, YouTube 계정에 만화 콘텐츠를 게시하고, 본인 게시물에 달린 댓글을 읽고 답글을 다는 용도로만 사용됩니다. 일반 사용자에게 제공되는 서비스가 아니며, 운영자 외 다른 사람은 앱에 로그인하지 않습니다.

2. 처리하는 정보

  • 운영자 계정의 접근 토큰: Google(YouTube), Meta(Instagram·Threads) OAuth로 발급된 토큰. 운영자 본인 계정에 게시하기 위해서만 사용합니다.
  • 운영자 게시물에 달린 공개 댓글: 댓글 내용과 작성자 공개 사용자명. 답글 작성과 스팸·악성 댓글 숨김 처리에만 사용합니다.
  • 운영자 게시물의 성과 지표: 조회수, 좋아요, 댓글 수 등 집계 통계.

운영자는 댓글 작성자의 비공개 정보, 연락처, 위치 정보를 수집하지 않으며, 수집한 정보를 판매하거나 광고 목적으로 제3자에게 제공하지 않습니다.

3. Google 사용자 데이터 (YouTube API)

앱은 YouTube API Services를 사용합니다. 앱이 요청하는 권한은 운영자 본인의 YouTube 채널에 동영상을 업로드하고 댓글을 관리하는 데 필요한 범위로 한정됩니다. 앱이 Google API에서 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

YouTube API 사용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다. 앱의 Google 계정 접근 권한은 Google 보안 설정 페이지에서 언제든 철회할 수 있습니다.

4. 보관 및 보안

토큰과 데이터는 운영자가 관리하는 서버에 암호화된 환경 변수와 데이터베이스로 보관하며, 외부에 공개하지 않습니다. 댓글 데이터는 최대 12개월 보관 후 삭제합니다. 접근 토큰은 권한을 철회하거나 앱 사용을 중단하면 즉시 삭제합니다.

5. 데이터 삭제 요청

본인의 댓글 데이터 삭제를 원하시면 데이터 삭제 안내 페이지를 참고하거나 아래 이메일로 요청해 주세요. 요청을 받은 날로부터 30일 이내에 삭제합니다.

Privacy Policy

Effective date: November 15, 2026

This policy describes how the operator of the "Gorani Toon" channel ("we") handles information when using our internal automation tool, Gorani Toon Autopilot (the "App").

1. Purpose of the App

The App is used only by the channel operator to publish comic content to the operator's own Instagram, Threads and YouTube accounts, and to read and reply to comments on those posts. It is not a public service and no one other than the operator signs in to it.

2. Information we process

  • Access tokens for the operator's own accounts, issued via Google (YouTube) and Meta (Instagram, Threads) OAuth, used solely to publish to the operator's accounts.
  • Public comments on the operator's posts, including comment text and the commenter's public username, used only to reply and to hide spam or abusive comments.
  • Aggregate performance metrics for the operator's posts (views, likes, comment counts).

We do not collect commenters' private information, contact details or location, and we do not sell or share any information with third parties for advertising.

3. Google user data (YouTube API Services)

The App uses YouTube API Services. The scopes requested are limited to uploading videos to, and managing comments on, the operator's own YouTube channel. The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

By using YouTube API Services, the YouTube Terms of Service and the Google Privacy Policy also apply. Access can be revoked at any time via the Google security settings page.

4. Storage and security

Tokens and data are stored on a server controlled by the operator, in encrypted environment variables and a private database, and are never made public. Comment data is deleted after at most 12 months. Access tokens are deleted immediately when access is revoked or the App is no longer used.

5. Data deletion

To request deletion of your comment data, see the Data Deletion page or email us. We delete requested data within 30 days.
